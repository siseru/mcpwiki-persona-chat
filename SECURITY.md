# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.
Use GitHub's private vulnerability reporting ("Security" tab → "Report a vulnerability") for this repository.
We aim to acknowledge reports within 5 business days.

## Scope

The extension code (`src/`), the infrastructure definitions (`src/infra/`, including the shared-account guard) and the CI workflows.

---

## 脆弱性の報告（日本語）

セキュリティ上の問題は **公開 Issue にしないでください**。このリポジトリの「Security」タブ →「Report a vulnerability」（非公開の脆弱性報告）からご連絡ください。5 営業日以内の一次回答を目指します。
